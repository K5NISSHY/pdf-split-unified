PDF 1ページ分割ツール（Windows 11）
====================================
バージョン: 1.1.0
製作者: K5NISSHY


フォルダー構成
--------------
pdf_splitter.py   分割ツール本体
起動.bat          ダブルクリックで起動するファイル
README_使い方.txt この説明書

必要なもの
----------
- Windows 11
- Python 3.10以降
- Excelブック（.xlsx または .xlsm）

Pythonの準備
------------
起動.batが「Python was not found」と表示した場合は、Pythonが未インストールか、PATHに登録されていません。
https://www.python.org/downloads/windows/ からPython 3をインストールしてください。
インストール画面で「Add python.exe to PATH」を有効にしてから、起動.batをもう一度実行します。

ライブラリ
----------
`起動.bat` は、まず `py -3`、利用できない場合は `python` でPythonを探します。Python 3.10以降が必要です。起動時に必要なライブラリを確認し、不足していれば自動でインストールします。初回のインストール時はインターネット接続が必要です。

- pypdf: PDFを読み込み、1ページずつ書き出します。
- openpyxl: Excel（.xlsx / .xlsm）からセルの値を読み込みます。
- tkinter: 画面表示に使います。Pythonに付属する標準ライブラリです。

手動でインストールする場合は、コマンドプロンプトで次を実行します。

  py -3 -m pip install --user pypdf openpyxl

「py」が使えない場合は、次を実行します。

  python -m pip install --user pypdf openpyxl

使い方
------
1. 起動.batをダブルクリックします。
2. 「分割するPDF」の「参照...」でPDFを選びます。
3. 「Excelファイル」の「参照...」でExcelを選びます。選択後、シート欄にシート名が表示されます。
4. 使用するシートを選び、「セル番地」に値を読むセル（例: A1、B3）を入力します。
   初期値はA1です。シート欄の初期選択はExcelのアクティブシートです。
5. 出力先フォルダーを選びます。PDFを選ぶと、そのPDFと同じフォルダーが初期値になります。
6. 「分割を実行」を押します。

出力例
------
選択したシートのB3が ABC123、PDFが5ページの場合：
ABC123_001.pdf
ABC123_002.pdf
ABC123_003.pdf
ABC123_004.pdf
ABC123_005.pdf

ページ番号は元PDFの先頭を001として付けます。1000ページ以上では桁数を必要に応じて増やします。
元PDFは読み取りのみで、変更しません。

入力の条件とエラー
------------------
- 指定したセルが空欄の場合は処理を中止します。
- Windowsのファイル名に使えない文字（\ / : * ? " < > |）、制御文字、末尾の空白・ピリオド、予約名は拒否します。
- セル番地はA1、B3などの形式で指定します。
- 暗号化PDFは空のパスワードで開けない場合にエラーを表示します。
- 壊れたPDFや読み込めないExcelはエラーを表示します。
- 出力予定のファイルが1つでも既にある場合、何も上書きせず処理を中止します。
- PDFを1ページずつ個別ファイルに保存します。既存ファイルは削除・変更しません。

数式セルについて
----------------
セルに数式が入力されている場合、このツールは数式自体を計算せず、Excelがブックに保存した計算結果をファイル名に使います。計算結果が保存されていない、または空の場合はエラーになります。その場合はExcelでブックを開き、再計算して保存してから、もう一度実行してください。数式を変更した後は、計算結果が古くならないようExcelで再計算・保存してください。
