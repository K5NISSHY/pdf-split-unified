# PDF 1ページ分割ツール

PDFを1ページずつに分割し、Excelで指定したセルの値を使ってファイル名を付ける Windows 11 向けツールです。

- **バージョン:** 1.1.0
- **製作者:** K5NISSHY

## フォルダー構成

- `pdf_splitter.py`: 分割ツール本体
- `起動.bat`: ダブルクリックで起動
- `README_使い方.txt`: テキスト形式の使い方

## 必要なもの

- Windows 11
- Python 3.10 以降
- Excel ブック（`.xlsx` または `.xlsm`）

## Python とライブラリの準備

`起動.bat` を実行したときに「Python was not found」と表示された場合は、[Python公式ダウンロードページ](https://www.python.org/downloads/windows/)から Python 3 をインストールしてください。インストール時に「Add python.exe to PATH」を有効にし、起動し直します。

`起動.bat` は `py -3`、利用できない場合は `python` で Python を探します。Python が見つからない場合は、Python 3.10 以降をインストールしてください。起動時に `pypdf` と `openpyxl` が利用できるか確認し、不足していれば `pip install --user pypdf openpyxl` で自動インストールします。そのため、初回のインストール時にはインターネット接続が必要です。

- `pypdf`: PDFの読み込みと1ページごとの書き出し
- `openpyxl`: `.xlsx` / `.xlsm` ブックからセル値を読み込み
- `tkinter`: 画面表示（Pythonに付属する標準ライブラリ）

手動でライブラリをインストールする場合は、コマンドプロンプトで次を実行してください。

```text
py -3 -m pip install --user pypdf openpyxl
```

`py` コマンドが使えない場合:

```text
python -m pip install --user pypdf openpyxl
```

## 使い方

1. `起動.bat` をダブルクリックします。
2. 「分割するPDF」の「参照...」からPDFを選びます。
3. 「Excelファイル」の「参照...」からExcelブックを選びます。シート欄にシート名が表示されます。
4. シートを選び、セル番地（例: `A1`、`B3`）を入力します。初期値は `A1` で、シート欄はExcelのアクティブシートが初期選択されます。
5. 出力先フォルダーを選びます。PDF選択後は、PDFと同じフォルダーが初期値になります。
6. 「分割を実行」を押します。

## 出力例

シートで指定したセルの値が `ABC123`、PDFが5ページの場合:

```text
ABC123_001.pdf
ABC123_002.pdf
ABC123_003.pdf
ABC123_004.pdf
ABC123_005.pdf
```

元PDFは読み取りのみで変更しません。ページ番号は先頭を `001` とし、1000ページ以上では必要に応じて桁数が増えます。

## 入力条件とエラー

- 指定したセルが空欄の場合、処理を中止します。
- ファイル名に使えない文字（\\ / : * ? " < > |）、制御文字、末尾の空白・ピリオド、Windowsの予約名は使用できません。
- セル番地は `A1`、`B3` などで指定します。
- 空のパスワードで開けない暗号化PDFは処理できません。
- 壊れたPDFや読み込めないExcelはエラーになります。
- 出力予定のファイルが1つでも存在する場合、上書きせず処理を中止します。
- 既存ファイルは削除・変更しません。

## Excelの数式セル

数式セルでは数式自体を計算せず、Excelブックに保存された計算結果をファイル名に使います。計算結果が保存されていない、または空の場合は処理を中止します。その場合はExcelでブックを開き、数式を再計算して保存してから実行してください。数式を変更した後も、計算結果が古くならないようExcelで再計算・保存してください。
